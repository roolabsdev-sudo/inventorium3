Scanners

Scanner codes

A scanner code turns a spare phone or tablet into a scanner. On that device, open the sign-in page (login.html), choose Use a scanner code and type the code. From then on the device can check items in and out and nothing else, until someone signs out of it. Each code works for the number of devices you choose and stops working when it expires. Turn a code off if it gets shared further than you meant.
